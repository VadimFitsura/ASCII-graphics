# Changelog

## [1.0.0] - 2023-11-14

### Добавлено
- Базовая реализация консольной ASCII-анимации со светлячками (`*`).
- Механика случайного движения светлячков по экрану.
- светлячки отражаются от границ терминала.
- Механика случайной остановки светлячков на время.
- Механика смены яркости символов с использованием ANSI-кодов.
- неблокирующий ввод с клавиатуры с использованием стандартных модулей.
- Интерактивное управление.
- Статус-бар, отображающий количество светлячков, текущую скорость и статус паузы.
- Корректное завершение программы: возврат стандартного цвета терминала, показ курсора и восстановление настроек консоли при выходе.
- Добавлен файл `README.md` с описанием и инструкциями.
- Добавлен файл `LICENSE`.
